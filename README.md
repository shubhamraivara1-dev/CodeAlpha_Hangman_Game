# CodeAlpha - Basic Chatbot 🤖

A rule-based conversational chatbot built in Python as part of the **CodeAlpha Python Programming Internship**.

## 📌 Features

- Responds to common greetings and friendly questions.
- Provides real-time date and time updates using the `datetime` module.
- Handles unknown queries with a helpful fallback message.
- Simple exit commands (`bye`, `exit`, `quit`).

## 🛠️ Concepts Used

- Rule-based pattern matching
- Functions & Infinite Loops (`while True`)
- `datetime` module for system time/date
- String methods (`lower()`, `strip()`, `in` operator)
